# AIKYN Director R&D

Исследовательский контур AIKYN: происхождение идей, проверяемые гипотезы, воспроизводимые эксперименты и сохранение результатов между рабочими сессиями.

**Статус: активная исследовательская работа.** Этот репозиторий — публичная документация. Готовая универсальная AGI-система или подтверждение всех исследовательских гипотез здесь не заявляются.

## Направление работы

- Сохранять связь между вопросом, источником, экспериментом и выводом.
- Сопоставлять исследовательские объекты и зависимости в TABLE.
- Отделять найденную историю идеи от доказательства её работоспособности.
- Передавать проверяемые постановки инженерному контуру и получать измеримые результаты.

## Связь с AIKYN-LAB

[AIKYN-LAB](https://github.com/agihomecore/AIKYN-LAB-PUBLIC) описывает инженерное направление AIKYN/Galymzhan OS: долговременную память, операторский слой и управляемую работу с инструментами. Director R&D сосредоточен на исследовательском методе, источниках и оценке результатов. Состояние реализации определяется конкретной версией и испытаниями.

## Граница публикации

Публикуются специально подготовленные описания и результаты с обозначенными ограничениями. Внутренние архивы, персональные данные, инфраструктурные адреса и секреты сюда не включаются. Содержание публичного репозитория не равно полному исследовательскому архиву.

В этой начальной редакции нет пакета экспериментальных результатов, достаточного для независимого подтверждения исследовательских гипотез. Такие пакеты добавляются после проверки источников, воспроизводимости и права публикации.
