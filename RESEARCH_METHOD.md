# Исследовательский метод

Наблюдение → вопрос → гипотеза → критерий опровержения → эксперимент → результат → проверка → публикация.

Для результата фиксируются источник, версия метода, входные данные, условия, ожидаемый исход, измерения, неопределённость и ограничения. Отрицательные результаты сохраняются. Исторический источник подтверждает происхождение идеи, но не физическое или техническое утверждение.

Статусы: **факт** — подтверждён в указанных условиях; **наблюдение** — зафиксированное явление; **гипотеза** — проверяемое предположение; **результат эксперимента** — измерение с методом и пределами применимости.

Критерий готовности: доступный метод, воспроизводимые материалы, проверка результата и ясные ограничения. Слова «PASS» без предмета и условий проверки недостаточно.
