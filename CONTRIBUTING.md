# Как предложить изменение

В предложении укажите вопрос, источник, ожидаемый результат и способ проверки. Для исправления документа приведите точное место и обоснование. Для эксперимента — метод, данные, версии и ограничения.

Не размещайте персональные данные, пароли, ключи, внутренние адреса и приватные материалы в issues, PR или файлах. Публикуйте только то, на что у вас есть права. Исследовательские предположения обозначайте явно.

Изменения рассматриваются через pull request. Не меняйте действующую лицензию и авторство без согласования.
